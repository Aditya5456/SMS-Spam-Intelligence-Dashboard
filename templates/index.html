1Project introduction

What is SMS spam?

SMS spam is any unwanted text message sent in bulk, usually to advertise, to trick people into calling premium-rate numbers, or to steal personal and banking details (phishing). Legitimate personal messages are called ham.

Why detection matters in telecommunications

Telecom operators deliver billions of messages. Spam wastes network capacity, annoys subscribers and causes real financial losses through fraud. Filtering it automatically protects users and the operator's reputation.

Why machine learning?

Hand-written rules ("block every message containing free") are easy for spammers to dodge and also block genuine messages. A machine-learning model learns patterns from thousands of labelled examples and can be retrained when spam changes.

Why text classification?

Each SMS must be assigned to one of two classes, ham or spam. Because the input is free text, we first convert words into numbers (TF-IDF) and then train a classifier on those numbers.

Why a Support Vector Machine?

An SVM finds the separating boundary with the widest possible margin between the two classes. It works well with the very high-dimensional, sparse features produced from text, and kernels let it learn non-linear boundaries without computing new features explicitly.

Data leakage prevention. Duplicate messages are removed before splitting so the same text cannot appear in both sets. 6Text preprocessing

Raw messages are cleaned before they are converted into numbers. The same cleaning function is used for training, testing and the live tester, so every message is treated identically.

  1. Decode HTML codes. The real dataset stores some characters as web codes, for example &lt;#&gt; (a placeholder for a number) and &amp; (meaning "&"). Decoding them first stops fake words such as "lt" and "gt" from appearing.
  2. Lowercase. "FREE" and "free" become the same word.
  3. Replace links and currency symbols. Web addresses become the word url; £, $, € and ₹ become money. Spam often contains these, so we keep the signal but not the exact address.
  4. Remove punctuation and symbols. Only letters, digits and spaces are kept. Digits are kept because premium phone numbers and prize amounts are strong spam clues.
  5. Remove extra whitespace. Multiple spaces collapse into one.
  6. Stopword removal (inside TF-IDF). Very common words such as "the", "is", "you" carry little meaning and are ignored, using scikit-learn's English stopword list.
  7. TF-IDF feature extraction. The cleaned text is turned into a numeric vector (next sections).

8TF-IDF feature extraction

TF-IDF converts text into numerical features that the machine-learning model can use.

TF (term frequency) measures how often a word appears in one message. IDF (inverse document frequency) measures how rare the word is across all training messages: idf(t) = ln((1 + N) / (1 + df(t))) + 1. A word gets a high TF-IDF weight when it is frequent in this message but rare overall, for example "prize" in a spam SMS.

Each message becomes a long vector with one position per vocabulary term (single words and two-word phrases). Most positions are zero, so scikit-learn stores the result as a sparse matrix. Each row is normalised to unit length so long and short messages are comparable.

9Support Vector Machine — main model

Hyperplane

The SVM separates spam from ham with a hyperplane wᵀx + b = 0 in the TF-IDF feature space. This is a discriminant function: f(x) = wᵀx + b > 0 means spam, < 0 means ham.

Margin

Among all separating hyperplanes, the SVM chooses the one with the widest gap (margin = 2 / ‖w‖) to the nearest messages of each class. A wide margin generalises better to new messages.

Support vectors

Only the training messages lying on or inside the margin determine the boundary. These are the support vectors; all other messages could be removed without changing the model.

Soft margin and C

Real data overlaps, so slack variables ξ allow some mistakes. The objective is minimise ½‖w‖² + C Σ ξₙ. Large C punishes mistakes strongly (narrow margin); small C allows more mistakes (wider margin).

Kernel

A kernel k(x, x′) measures similarity between two messages. The decision function becomes f(x) = Σ aₙ tₙ k(xₙ, x) + b, summed over support vectors only. Linear: xᵀx′. RBF: exp(−γ‖x − x′‖²). Polynomial: (γ xᵀx′ + 1)².

Kernel trick

A kernel equals a dot product in a higher-dimensional feature space, φ(x)ᵀφ(x′), but is computed without ever building φ(x). This lets the SVM learn curved boundaries at the cost of a simple similarity calculation.

Train the SVM

C accepts any value from 0.001 to 1000 (presets are suggested). Gamma is ignored by the linear kernel. "Balanced" gives the rarer spam class a larger penalty for mistakes.

10Kernel experiment and hyperparameter tuning

The same training and test split is used for every kernel. The polynomial kernel uses degree 2 with coef0 = 1, because higher degrees on sparse TF-IDF vectors produce extremely small similarity values. Results are measured on this dataset only; no kernel is universally better.

Uses the C, gamma and class-weight values from the SVM panel.

Grid search (cross-validation on the training set)

Seven preset configurations are tried with stratified 3-fold cross-validation on the training data only, scoring by F1 for the spam class. TF-IDF is refitted inside each fold. The best configuration is then trained on the full training set and evaluated once on the untouched test set.

Takes about 20–60 seconds on the full Kaggle dataset.

11Bayesian logistic regression

Logistic regression

Models the probability directly: p(spam | x) = σ(wᵀx + b), where σ(a) = 1 / (1 + e⁻ᵃ). This is a probabilistic discriminative model.

Prior

Before seeing data we assume each weight is small: p(w) = N(0, σ²p I). The prior variance σ²p controls how far weights may move from zero.

Posterior

p(w | data) ∝ p(data | w) · p(w). For logistic regression this posterior has no closed form, so exact Bayesian inference is not possible.

MAP estimate

wMAP maximises the posterior: minimise Σ [ln(1 + eᵃⁿ) − tₙaₙ] + ‖w‖² / (2σ²p). Implemented here with L-BFGS using the exact gradient.

Laplace approximation

The posterior is approximated by a Gaussian centred at wMAP: q(w) = N(wMAP, S), with S⁻¹ = Σ yₙ(1 − yₙ) xₙxₙᵀ + I / σ²p (the Hessian).

Predictive probability

p(spam | x) ≈ σ(κ(s²) μ), μ = wMAPᵀx, s² = xᵀSx, κ = (1 + πs²/8)−½ (probit approximation). Uncertain inputs are pulled toward 0.5.

Honest implementation note. This is not scikit-learn's LogisticRegression relabelled. The MAP weights, the Hessian, the Laplace covariance S and the moderated predictive probabilities are computed explicitly in app.py. Because S is a full (k + 1) × (k + 1) matrix, the k most informative TF-IDF features are first selected with a chi-square test on the training set; the intercept gets a weak N(0, 100) prior. With a 0.5 threshold the moderated and MAP probabilities give the same class (κ only shrinks the activation), but the probabilities and the ranking used for ROC-AUC differ. Generative vs discriminative: a generative model (for example Naive Bayes) would model p(x | class) and p(class) and apply Bayes' theorem; logistic regression and the SVM skip modelling the messages and learn the boundary directly.

Observed test-set performance

Accuracy

Share of all test messages classified correctly: (TP + TN) / total.

Precision

Of the messages flagged as spam, how many really were spam: TP / (TP + FP). Low precision means genuine messages get blocked.

Recall

Of the real spam messages, how many were caught: TP / (TP + FN). Low recall means spam slips through.

F1-score

Harmonic mean of precision and recall; high only when both are high.

Specificity

Share of ham messages correctly left alone: TN / (TN + FP).

ROC-AUC

Probability that a random spam message gets a higher score than a random ham message. Uses the SVM decision score and the Bayesian predictive probability.

Precision–recall trade-off and decision threshold

Both models output a score, and a message is called spam when the score passes a threshold. Moving the threshold trades false positives (blocked genuine messages) against false negatives (spam that gets through). For an operator, blocking a real customer message is usually the more costly mistake.

Measured on the same test set. The default threshold everywhere else on this page is 0.50. This explorer does not change the trained model.

Cross-validation check

The results above come from one 80/20 split. Stratified 5-fold cross-validation repeats the whole pipeline five times on different splits of the unique messages (TF-IDF and both models are refitted inside every fold) and reports the mean and standard deviation. A small standard deviation means the single-split result is stable.

Uses the current SVM and Bayesian LR settings. Takes a few seconds on the full dataset.

14Linear regression demonstration

This module covers Practical 1, "implement linear regression to perform prediction". It uses simple numbers derived from the loaded messages: it predicts the character length of an SMS from its word count. Linear regression is not used to classify spam anywhere in this project.

Maximum likelihood → least squares

Assume each target is a linear function plus Gaussian noise: t = wᵀφ(x) + ε, ε ~ N(0, σ²). The log-likelihood of N training points is

ln p(t | w, σ²) = −(1 / 2σ²) Σ (tₙ − wᵀφ(xₙ))² − (N / 2) ln(2πσ²)

Only the first term depends on w, so maximising the likelihood is exactly minimising the sum of squared errors E(w) = ½ Σ (tₙ − wᵀφ(xₙ))².

Closed-form solution

wML = (ΦᵀΦ)⁻¹ Φᵀt     σ²ML = (1/N) Σ (tₙ − wMLᵀφ(xₙ))²

Below, w is computed directly from these normal equations with NumPy and checked against scikit-learn. Robust regression (Huber loss) uses squared error for small residuals and absolute error for large ones, so outliers pull the line less.

15Ridge regression and Bayesian linear regression

Ridge regression

E(w) = ½ Σ (tₙ − wᵀφ(xₙ))² + (λ/2)‖w‖²  ⇒  w = (λI + ΦᵀΦ)⁻¹Φᵀt

The penalty shrinks coefficients toward zero, which reduces variance and helps when features are correlated. Ridge is the MAP solution of linear regression with a Gaussian prior on w.

Bayesian linear regression

Instead of a single w, a Gaussian posterior over w is kept, giving a predictive mean and a predictive standard deviation for each prediction. scikit-learn's BayesianRidge also estimates the noise precision α and weight precision λ from the data.

Task: predict SMS character length from five standardised features — word count, average word length, digit count, uppercase count and punctuation count.

    18Conclusion and submission

    This project builds a complete SMS spam detection system around a Support Vector Machine. Messages are validated, cleaned and converted to TF-IDF features without data leakage; an SVM with selectable kernels is trained and evaluated on a held-out test set; and a Bayesian logistic regression model using the Laplace approximation provides a probabilistic comparison. Separate regression modules demonstrate maximum likelihood, least squares, robust, polynomial, ridge and Bayesian linear regression from the Unit-2 syllabus. The measured results for the currently loaded dataset are listed in the key findings above.

    Limitations and future scope

    The dataset is English-only and several years old, so modern spam styles (for example delivery-scam links or regional languages) are under-represented. Results come from one random split; repeated cross-validation would give more stable estimates. Future work could add multilingual data, character n-grams to handle deliberate misspellings, threshold tuning to reduce false positives, and deployment as an operator-side filtering API.
